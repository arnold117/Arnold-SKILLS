# Arnold SKILLS

Arnold 的个人 Claude Code skill 库。

```
/plugin install arnold-skills --marketplace arnold117/Arnold-SKILLS
```

- [grill-wide](skills/grill-wide/SKILL.md)：先广后深地追问方案，按可逆性×影响只深挖关键分支，产出决策文件和 spec
- [map-wide](skills/map-wide/SKILL.md)：把一个会话装不下的事画成地图，拆成决定票和实现票
- [build-wide](skills/build-wide/SKILL.md)：把实现票做出来，一张自己做，一批派子 agent 并行
- [lean-verify](skills/lean-verify/SKILL.md)：实现后用最少的测试证明关键行为正确
